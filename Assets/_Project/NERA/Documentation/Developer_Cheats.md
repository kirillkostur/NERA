# NERA — Developer Cheat Console

Дата проверки: 2026-08-27

## Назначение

Developer Cheat Console — статический uGUI-prefab для ручной проверки
прогрессии, погоды, обслуживания, апгрейдов, инвентаря и IO без изменения
балансных конфигов.

- открыть: клавиша `` ` `` (`BackQuote`);
- закрыть: `Esc`;
- при открытом окне управление игроком блокируется через отдельный owner-lock;
- время игры не останавливается;
- все подписи и кнопки созданы в prefab заранее, runtime-код не строит UI и не
  генерирует названия кнопок.

Prefab:
`Assets/_Project/NERA/Prefabs/Developer/P_DeveloperCheatConsole.prefab`.

Runtime instance расположен корневым объектом `DeveloperCheatConsole` в
`MainScene` и переносится в `DontDestroyOnLoad` при запуске.

## Включение в Editor и сборках

На компоненте `DeveloperCheatConsoleController` в prefab есть три независимых
флага:

| Флаг | Значение по умолчанию | Назначение |
|---|---:|---|
| `Enabled In Editor` | `true` | доступность в Play Mode Unity Editor |
| `Enabled In Development Build` | `true` | доступность в Development Build |
| `Enabled In Release Build` | `false` | доступность в обычной release-сборке |

Если соответствующий флаг выключен, объект уничтожается в `Awake` и клавиша
`` ` `` ничего не открывает. Для обычного релиза консоль по умолчанию отключена.

После изменения структуры кнопок prefab пересобирается командой меню:
`NERA -> Developer -> Rebuild Cheat Console`. Builder также обновляет его
instance в `MainScene`.

В Play Mode окно можно открыть и без фокуса Game View через меню
`NERA -> Developer -> Open Cheat Console (Play Mode)`. Это вспомогательный
способ для визуальной проверки; в игре основным способом остаётся клавиша
`` ` ``.

## Команды

### Навигация и локации

| Кнопка | Действие |
|---|---|
| `ДОМОЙ` | загружает `Player_Station` со spawn point `Station_Start` |
| `ЭКСПЕДИЦИЯ 1`–`8` | вызывает штатный `Discover` для выбранной экспедиции и игнорирует дальность дрона |
| `СИГНАЛ 1`–`12` | принудительно показывает выбранный Unknown Signal и игнорирует дальность антенны |

Сигнал всё ещё требует хотя бы один уже открытый Expedition-sector с
настроенным `MapSlot`: без него на терминальной карте негде поставить marker.
Если доступно несколько секторов, используется текущая штатная логика — один
из открытых секторов выбирается случайно. Повторное нажатие может вернуть уже
использованный сигнал для повторной проверки.

### Язык

Кнопка языка находится внутри окна читов слева внизу. Она показывает текущий
язык и переключает локаль между русской и английской по каждому нажатию.
Прежняя редакторская подсказка `[F8] LANGUAGE` поверх игрового экрана удалена;
вне открытых читов отдельный debug-переключатель больше не отображается.

### Погода и обслуживание

| Кнопка | Действие |
|---|---|
| `ЯСНО` | устанавливает `StationWeather.Clear` |
| `ПЕСОК` | запускает штатную песчаную бурю |
| `ОЧИСТИТЬ` | устанавливает `Condition = 1` всем зарегистрированным `MaintainableObject` |
| `ЗАГРЯЗНИТЬ` | устанавливает `Condition = 0` всем зарегистрированным `MaintainableObject` |

Сейчас загрязнение, поломка и очистка используют общий параметр `Condition`,
поэтому `ЗАГРЯЗНИТЬ` делает объект полностью неработоспособным.

### Полный апгрейд станции

Кнопки `ТУРЕЛЬ 1`, `ТУРЕЛЬ 2`, `ДРОН`, `АНТЕННА`, `БАТАРЕЯ` и `ПАНЕЛЬ`
находят в `ItemCatalog_Default` совместимую Engineering Part для каждого
свободного слота и устанавливают все найденные детали одним штатным вызовом
`StationSystemsController.TryInstallParts`.

Инвентарь при этом не используется и детали из него не расходуются. Уже
занятые слоты сохраняются без замены.

### Включение и выключение систем

Возле кнопок полного апгрейда находятся зелёная `ВКЛ` и красная `ВЫКЛ`.
Они принудительно меняют `RequestedActive` соответствующего объекта:

- `ТУРЕЛЬ 1` и `ТУРЕЛЬ 2` управляются независимо;
- `ДРОН`, `АНТЕННА`, `ПАНЕЛЬ` включаются и выключаются отдельно;
- `БАТАРЕЯ` дополнительно включает или выключает общую энергосеть станции;
- отдельный блок `ТЕРМИНАЛ` справа сверху управляет системой `Terminal`;
  выключение также закрывает открытый интерфейс терминала.

Это debug-команды: включение обходит проверки заряда, загрязнения,
обслуживания и незавершённой экспедиции дрона. Обычные игровые вызовы
`SetRequestedActive` и их ограничения не изменены.

### IO

| Кнопка | Действие |
|---|---|
| `ЗАСПАВНИТЬ IO` | создаёт один `IO_Blue_Weak` в пяти метрах перед игроком — внутри его attack range 6 m |
| `УБИТЬ IO` | наносит смертельный урон всем активным `IOEnemyController` текущей локации |

Debug-spawn не получает persistent ID и после перезагрузки сцены не
восстанавливается. Убийство проходит через штатный `TakeDamage`, поэтому
срабатывают quest-сигналы и обычный drop.

### Выдача предметов

В правой части prefab находятся 25 статических строк — по одной на каждый
Engineering Part из `Configs/Items/Item_EngineeringPart`. Детали разбиты на
блоки по фактической совместимости из `EngineeringPartDefinition`:

- `ДРОН:` — 5 деталей;
- `АНТЕННА:` — 4 детали;
- `ПАНЕЛЬ:` — 4 детали;
- `БАТАРЕЯ:` — 6 деталей;
- `ТУРЕЛИ:` — 6 деталей, общих для обеих турелей.

Внутри блока детали отсортированы по первому совместимому `Slot_N`. Кнопка
`+1` добавляет один экземпляр соответствующего `ItemData` в первый свободный
backpack slot. Если рюкзак заполнен, предмет не добавляется; причина выводится
в Unity log.

## Проверка после изменений

1. Запустить `NERA -> Developer -> Rebuild Cheat Console`.
2. Проверить отсутствие compile errors.
3. Запустить `DeveloperCheatConsoleTests` и
   `DeveloperForceRevealSignalBypassesAntennaRange`.
4. В Play Mode открыть окно клавишей `` ` `` и проверить закрытие через `Esc`.
5. В `MainScene` убедиться, что существует только один root
   `DeveloperCheatConsole`.
6. Перед release-сборкой оставить `Enabled In Release Build = false`.
