# Зоны орбит камеры

Система временно меняет шесть параметров `FreeLookCam`, когда игрок входит в
триггер, и восстанавливает значения камеры после выхода:

- `Top Rig`: `Height`, `Radius`;
- `Middle Rig`: `Height`, `Radius`;
- `Bottom Rig`: `Height`, `Radius`.

Плавность задаётся в том же профиле:

- `Blend In Duration` — время перехода при входе;
- `Blend Out Duration` — время возврата при выходе.

Значение по умолчанию — `0.35` секунды. `0` оставляет мгновенное
переключение. Height и Radius интерполируются через `SmoothStep`, поэтому
камера мягко начинает и заканчивает движение.

## Создание профиля

1. В Project выбрать `Create -> NERA -> Camera -> Free Look Orbit Profile`.
2. Назвать asset по назначению, например `CameraOrbit_Corridor`.
3. Заполнить `Top Rig`, `Middle Rig` и `Bottom Rig`.
4. Настроить `Blend In Duration` и `Blend Out Duration`.

Профиль содержит только параметры орбит. Исходные значения сохранять в
отдельном профиле не нужно: они автоматически читаются из `FreeLookCam`.

## Создание зоны

1. Создать пустой GameObject в сцене.
2. Добавить `BoxCollider` или другой 3D `Collider`. Если коллайдера нет,
   компонент автоматически создаст `BoxCollider`.
3. Добавить `FreeLookCameraOrbitZone`.
4. Назначить созданный профиль в поле `Profile`.
5. Изменить размер и положение коллайдера под комнату, коридор или узкое место.

`Is Trigger` включается компонентом автоматически. Игрок определяется по тегу
`Player`, включая коллайдеры на дочерних объектах игрока.

## Пересекающиеся зоны

Поле `Priority` находится на зоне, а не в профиле:

- зона с большим `Priority` имеет преимущество;
- при одинаковом значении используется зона, в которую игрок вошёл последней;
- после выхода снова применяется предыдущая активная зона;
- после выхода из всех зон восстанавливаются текущие базовые орбиты
  `FreeLookCam`.

На `FreeLookCam` в `Player.prefab` уже установлен
`FreeLookCameraOrbitController`. Добавлять его на каждый триггер не нужно.
