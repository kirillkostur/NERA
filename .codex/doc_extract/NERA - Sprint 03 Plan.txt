NERA — Sprint 03 Plan
Drone + Expedition Unlock
1. Назначение Sprint 03
Sprint 03 нужен, чтобы связать станцию, терминал и первую экспедицию в один понятный игровой flow.
После Sprint 01 у нас есть:
Player
Camera
Interaction
Scene transitions
Pickup placeholder
Technical build
После Sprint 02 у нас есть:
Station Offline
→ Restore Power
→ Terminal Online
→ Terminal Placeholder UI
Sprint 03 добавляет следующий шаг:
Terminal
→ Launch Drone
→ Scan Area
→ Discover Expedition 01
→ Show Expedition 01 in terminal
→ Allow travel to Expedition 01
2. Главная цель спринта
Цель
Сделать первый рабочий вариант системы дрона и открытия первой экспедиции.
Игрок должен:
включить питание станции;
открыть терминал;
перейти в раздел Drone;
нажать Launch Drone;
увидеть состояние сканирования;
получить результат: Expedition 01 discovered;
увидеть Expedition 01 в placeholder map/list;
выбрать Expedition 01;
перейти в сцену Expedition_01_FirstPlayable.
3. Почему это важно
До Sprint 03 переход в экспедицию может существовать только как debug transition.
Но для NERA важно, чтобы экспедиции открывались через логику мира:
станция
→ терминал
→ дрон
→ обнаружение
→ экспедиция
Это делает First Playable ближе к настоящей игре.
Главное ощущение:
Я сам обнаружил новую точку.
Теперь у меня есть причина туда пойти.

5. Игровой flow Sprint 03
5.1. Начальное состояние
После запуска сцены станции:
StationPowerState = Offline
DroneState = Locked
Expedition_01_Unlocked = false
Пока станция без энергии:
терминал выключен;
дрон недоступен;
Expedition 01 не отображается как доступная цель.
5.2. После восстановления питания
Когда игрок включает питание:
StationPowerState = Online
DroneState = Ready
Теперь в терминале доступен раздел:
Drone
5.3. Запуск дрона
Игрок открывает терминал:
NERA Station Terminal
Переходит в раздел:
Drone
Нажимает:
[Launch Drone]
После этого состояние меняется:
DroneState = Scanning
5.4. Сканирование
На Sprint 03 сканирование может быть placeholder.
Достаточно показать:
Drone scanning surrounding area...
Или:
Scan progress: 0% → 100%
Важно:
игрок понимает, что дрон что-то делает;
система не мгновенно телепортирует в экспедицию;
появляется ощущение обнаружения.
5.5. Результат сканирования
После завершения сканирования:
DroneState = ScanComplete
Expedition_01_Unlocked = true
UI показывает:
New expedition discovered:
Expedition 01 — Ancient Outpost
5.6. Открытие Expedition 01
После сканирования в терминале появляется доступная карточка:
Expedition 01
Ancient Outpost
Status: Discovered
Кнопка:
[Travel]
После нажатия:
Load Scene: Expedition_01_FirstPlayable

6.2. Расшифровка состояний

Дрон недоступен.
Используется, когда станция без питания.
Condition:
StationPowerState = Offline

Дрон готов к запуску.

Дрон выполняет placeholder scan.
Condition:
Launch Drone pressed
ScanComplete
Сканирование завершено.
Condition:
Expedition_01_Unlocked = true
7. Expedition Unlock Rules
7.1. Обычные экспедиции открывает дрон
Правило проекта:
Обычные экспедиции открывает дрон.
Это значит:
Expedition 01 открывается через Drone Scan;
Expedition 02–10 в будущем тоже могут открываться через Drone / Terminal progression;
? точки не открываются дроном.
7.2. ? точки открывает антенна
Важно не смешивать:
Drone = обычные экспедиции NERA
Antenna = ? точки / человеческие следы / прошлые миссии
В Sprint 03 антенны ещё нет.
Но архитектурно нельзя называть ? точки обычными expedition unlock.
7.3. Research и Translation не открывают локации напрямую
Research / Library / Translation могут давать:
подсказки;
понимание;
записи;
контекст;
новые смыслы.
Но не должны напрямую делать:
Translation Complete → Expedition unlocked
Для First Playable можно использовать их позже как условие понимания, но не как прямую кнопку открытия локации.

14. Player Experience Rules
14.1. Игрок должен понимать причину
Переход в Expedition 01 не должен выглядеть как меню выбора уровня.
Он должен ощущаться как результат действия:
Я включил станцию.
Я запустил дрон.
Дрон нашёл объект.
Теперь я могу туда пойти.
14.2. Не перегружать текстом
На Sprint 03 тексты должны быть короткие.
Хорошо:
New expedition discovered.
Ancient structure detected near the station.
Плохо:
Drone satellite triangulation module has detected anomalous architectural signal signature...
Для First Playable достаточно простой формулировки.

18. Критерии готовности Sprint 03
Sprint 03 считается готовым, если:
18.1. Drone
дрон заблокирован до включения станции;
после включения питания дрон становится доступен;
игрок может запустить сканирование из терминала;
во время сканирования видно состояние Scanning;
после сканирования появляется результат.
18.2. Expedition Unlock
Expedition 01 изначально скрыта или недоступна;
после scan result она становится Discovered;
unlock state хранится не в UI, а в отдельной системе;
UI получает состояние из системы.
18.3. Terminal UI
есть Drone section;
есть Expeditions / Map placeholder section;
до сканирования Expedition 01 недоступна;
после сканирования Expedition 01 отображается;
кнопка Travel появляется или становится активной.
18.4. Scene Travel
Travel загружает Expedition_01_FirstPlayable;
в билде сцена загружается;
игрок появляется в Expedition 01;
есть способ вернуться на станцию;
переход не требует debug-команд.
18.5. Technical
нет ошибок в Console;
нет Missing Scripts;
нет Missing Prefabs;
нет Missing Materials;
билд собирается;
полный flow работает в standalone build.

21. Риски Sprint 03
21.1. Риск: начать делать настоящего дрона
Проблема:
Хочется сделать модель, анимацию, запуск, полёт, камеру дрона.
Решение:
В Sprint 03 дрон — это система состояния и UI action.
Физический дрон можно добавить позже.
21.2. Риск: начать делать полноценную карту
Проблема:
Карта может занять слишком много времени.
Решение:
В Sprint 03 Map = список найденных экспедиций.
Настоящая карта будет отдельным документом и отдельным спринтом.
21.3. Риск: смешать Drone и Antenna
Проблема:
Можно случайно сделать так, что дрон открывает и обычные экспедиции, и ? точки.
Решение:
Drone открывает Expedition.
Antenna открывает ?.
В Sprint 03 антенну не делать.
21.4. Риск: сделать unlock внутри UI
Проблема:
Кнопка Launch Drone сама включает Expedition 01 внутри UI.
Решение:
UI только вызывает DroneScanController.
DroneScanController отдаёт result.
ExpeditionUnlockController меняет state.
UI только отображает state.
