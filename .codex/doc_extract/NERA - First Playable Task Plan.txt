NERA — First Playable Task Plan
АКТУАЛЬНОЕ УТОЧНЕНИЕ: Translation System удалена из актуального scope. Исторические задачи Translation в этом плане не подлежат реализации; см. «NERA — Current Scope Decisions», DD-001.
Назначение документа
First Playable Task Plan описывает конкретный список задач для создания первой рабочей версии NERA.
Этот документ не заменяет Production Bible. Production Bible отвечает на вопрос:
В каком порядке разрабатывать игру?
First Playable Task Plan отвечает на вопрос:
Какие конкретные задачи нужно сделать, чтобы собрать первый рабочий билд?
00. Цель First Playable
Главная цель
Собрать внутреннюю рабочую версию NERA, где игрок может пройти основной игровой цикл:
станция
↓
восстановление питания
↓
терминал
↓
дрон
↓
открытие экспедиции
↓
переход в экспедицию
↓
находка
↓
возвращение на станцию
↓
исследование
↓
обновление библиотеки
↓
частичный перевод
↓
намёк на следующую цель
First Playable — это не
не публичное демо;
не vertical slice;
не финальный арт;
не polished build;
не полная первая глава;
не версия для Steam;
не маркетинговый билд.
First Playable — это
рабочий игровой loop;
минимальный контент;
минимальный UI;
минимальный арт;
минимальная угроза;
минимальная атмосфера;
возможность самому проверить, интересна ли игра.
01. First Playable Core Flow
Игровая последовательность
First Playable должен проходиться так:
1. Игрок появляется на станции.
2. Терминал выключен.
3. Игрок осматривает станцию.
4. Игрок находит источник питания / солнечную панель.
5. Игрок выполняет long interaction: clean / repair.
6. Станция получает питание.
7. Терминал становится доступен.
8. Игрок открывает терминал.
9. Игрок запускает дрон.
10. Дрон возвращается с данными.
11. На карте появляется Expedition 01.
12. Игрок выбирает Expedition 01.
13. Игра загружает сцену экспедиции.
14. Игрок проходит локацию.
15. Игрок находит древнюю запись.
16. Игрок находит исследуемый объект.
17. Игрок встречает IO или след IO.
18. Игрок возвращается на станцию.
19. Игрок открывает Research UI.
20. Игрок исследует объект.
21. В Library появляется новая запись.
22. Перевод древней записи улучшается.
23. Игрок получает намёк на следующую экспедицию.
Главный критерий
После прохождения First Playable должен возникать вопрос:
Что дальше?
Если после прохождения не хочется идти во вторую экспедицию, loop нужно менять.

собрать один полный исследовательский loop

Если этот loop не работает, нужно менять темп, станцию, экспедицию или research-flow до того, как появятся 10 локаций и большой объём контента.
